# 🐢 黄缘龟桌宠

> 一只可爱的黄缘龟（Cuora flavomarginata）会在你的 Windows 任务栏上悠闲地爬行！

---

## ✨ 功能特性

- 🐢 **纯代码绘制黄缘龟** — 程序化绘制茶褐色圆拱壳 + 金黄色脊线 + 橄榄绿头部 + 头侧黄色条纹，真实还原黄缘龟外形
- 🎬 **多帧走路动画** — 4帧循环 + 轻微上下抖动
- 😄 **丰富表情** — 眨眼、眯眼笑、正常三种表情随机切换
- 💬 **随机气泡对话** — 乌龟会随机说"你好~""好无聊啊""晒太阳真舒服"等俏皮话
- 🖱️ **交互功能**
  - 左键拖拽：移动乌龟位置
  - 滚轮：调节爬行速度
  - 右键菜单：打招呼、随机动作、关于、退出
- 🪟 **任务栏专属模式** — 窗口置顶、透明背景、Tool 窗口不抢占焦点
- 🛡️ **单实例保护** — 防止重复启动

---

## 🚀 运行方式

### 方式一：一键启动（推荐）
双击 **`启动桌宠.bat`** 即可运行

### 方式二：命令行
```bash
pip install PyQt5
python 黄缘龟桌宠.py
```

### 方式三：手动安装依赖后运行
```bash
pip install -r requirements.txt
python 黄缘龟桌宠.py
```

## 🎮 操作说明

| 操作 | 功能 |
|------|------|
| 双击桌宠 | 打招呼 |
| 右键菜单 → 打招呼 | 显示气泡 |

## 🐢 关于黄缘龟

**黄缘盒龟（Cuora flavomarginata）** 是国家二级保护动物，
特征：
- 背甲呈深茶褐色，圆拱形
- 背甲中央有明显金黄色脊线
- 头部为橄榄绿，两侧有金黄色条纹
- 腹甲黄色，边缘黑色

> ⚠️ 本程序仅用于桌面娱乐，黄缘龟为国家保护动物，请勿购买、食用或伤害野生个体。
